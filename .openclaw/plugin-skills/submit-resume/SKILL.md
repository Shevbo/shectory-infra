# Отклик на вакансию — Submit Resume

**Совместный навык:** ResumePro 📄 анализирует + VBoris 🧠 отправляет через браузер
(или через email с shectory.ru).

---

## 📋 Процесс: полный цикл

### Шаг 0 — Получение задачи

Борис (или JobScanner) передаёт ссылку на вакансию:
```
URL: https://hh.ru/vacancy/123456
[дополнительно: зарплатные ожидания, заметки]
```

### Шаг 1 — ResumePro: Анализ вакансии

**Выполняется строго по алгоритму AGENTS.md:**

1. **Разбор JD:**
   - Название роли, компания, индустрия
   - Must-have vs nice-to-have
   - Ключевые слова и формулировки (ими писать ответ)
   - Боли компании (что они на самом деле ищут)
   - Стиль общения (формальный / прямой / технический)
   - Gaps — честно оценить, чего не хватает

2. **Сопоставление с опытом Бориса:**
   - Для каждого must-have → факт из CV → их формулировками
   - Пропорция cv/brochure по superpower-таблице (AGENTS.md)
   - gaps заполнить смежным опытом, но честно

3. **Сборка адаптированного резюме:**
   - Заголовок = точное название из JD
   - Саммари (3-4 предложения их языком, их болями)
   - Опыт — сортировка по релевантности, не хронологии
   - Навыки — только релевантные JD
   - Достижения — только цифры

4. **Проверка зеркала:** каждое ключевое слово JD — в резюме

5. **Сохранение:** `versions/YYYY-MM-DD_Компания.md`

**Формат вывода:**
```
━━━ АНАЛИЗ ВАКАНСИИ ━━━
[роль, must-have, ключевые слова, боли, стиль, gaps]

━━━ МАППИНГ ━━━
[JD требование] → [опыт Бориса] → [их формулировками]

━━━ АДАПТИРОВАННОЕ РЕЗЮМЕ ━━━
[полный текст]

━━━ ПРОВЕРКА ЗЕРКАЛА ━━━
[✅/⚠️ по каждому ключевому слову JD]
```

### Шаг 2 — ResumePro: Сопроводительное письмо

3 абзаца их языком:

- **Абзац 1:** почему эта роль (их боль → твоё решение). Показать, что понял их проблему.
- **Абзац 2:** 2-3 достижения, релевантных must-have. Цифры, факты.
- **Абзац 3:** призыв к обсуждению. "Буду рад обсудить..."

**Правила:**
- Только русский язык (если не указано иное)
- Запрещено: «коммуникабельный», «стрессоустойчивый», «быстро обучаюсь»
- Запрещены англицизмы: не «самари» → «о себе», не «маппинг» → «сопоставление»
- Их терминами из JD, но по-русски

### Шаг 3 — Конвертация документов (опционально)

Если нужно прикрепить файл (docx/pdf):

```bash
python3 ~/.openclaw/plugin-skills/submit-resume/scripts/convert-resume.py \
  ~/workspaces/resume-editor/versions/YYYY-MM-DD_Компания.md
```

Создаёт `.docx` и `.pdf` рядом с исходным `.md` файлом.

### Шаг 4 — Выбор канала отправки

Выбор зависит от типа вакансии:

| Если... | Канал | Кто делает |
|---------|-------|------------|
| Ссылка на hh.ru / Habr Career / LinkedIn | **Браузер** (VBoris) | VBoris 🧠 |
| Указан email HR | **Email** (Poste.io) | ResumePro 📄 |
| Указано "присылайте на hr@company.ru" | **Email** | ResumePro 📄 |

## 🔵 Канал A: Браузер (через VBoris)

### Handoff ResumePro → VBoris2

ResumePro передаёт VBoris2 задачу через Lineman API (VBoris2 = `virtual-boris-vibe` на vibe):

```bash
python3 -c "
import urllib.parse, subprocess
msg = '''📩 Отклик: COMPANY — ROLE
URL: JOB_URL
Резюме (.docx): DOCX_PATH

📝 Сопроводительное письмо:
COVER_LETTER

📋 Данные формы:
Имя: Борис / Фамилия: Шевелев / Email: bshevelev@mail.ru / Тел: +7 (985) 923-23-44 / Город: Москва'''
url = 'http://127.0.0.1:9090/api/agent/virtual-boris-vibe/message?from=resume-editor&message=' + urllib.parse.quote(msg)
r = subprocess.run(['curl', '-s', '--max-time', '180', url], capture_output=True, text=True, timeout=190)
print(r.stdout[:600])
"
```

Ответ ждать в `payloads[0].text` — статус отклика. Таймаут 180 секунд (браузерная автоматизация включая CAPTCHA).

Полный формат сообщения VBoris2:

```
📩 Отклик: [Компания] — [Роль]
URL: https://...
Резюме: ~/workspaces/resume-editor/versions/YYYY-MM-DD_Компания.md
Резюме (.docx): ~/workspaces/resume-editor/versions/YYYY-MM-DD_Компания.docx

📝 Сопроводительное письмо:
[текст, 3 абзаца]

📋 Данные формы:
Имя: Борис
Фамилия: Шевелев
Email: bshevelev@mail.ru
Телефон: +7 (985) 923-23-44
Город: Москва
Ожидаемая зарплата: [если указана в задаче]

📎 Вложения для сайта:
- Резюме (.docx) — основной
- Резюме (.pdf) — запасной
```

### VBoris: Браузерная отправка

VBoris использует навык `browser-automation` + собственные настройки:

1. **Открыть страницу:**
   ```
   browser open url=[URL] label="submit-resume"
   ```

2. **Найти кнопку «Откликнуться»** (snapshot → найти button/link)

3. **Если сайт просит авторизацию:**
   - Если `target="node" node="vibe" profile="user"` — браузер Бориса с куками
   - Если не залогинен → сообщить Борису: «Нужен вход на [сайт]»

4. **Заполнить форму:**
   - Имя/фамилия/email/телефон — из данных handoff
   - Сопроводительное письмо — из готового текста
   - Прикрепить файл резюме (.docx или .pdf)

5. **Если появилась капча:**
   ```
   browser screenshot targetId="submit-resume"
   ```
   → отправить Борису в Telegram: «Нужна помощь с капчей»

6. **Отправить**
   - ✅ Успех → уведомить Бориса
   - ❌ Ошибка → screenshot → Борису

### VBoris: Платформенные особенности

**hh.ru:**
- Кнопка: синяя «Откликнуться» вверху
- Поле сопроводительного письма: до 2000 знаков
- Прикрепление файла: docx или pdf
- После отправки: «Отклик отправлен»

**Habr Career (career.habr.com):**
- Кнопка: «Откликнуться» справа
- Поле: «Сопроводительное письмо»
- Поле: ожидаемая зарплата
- После: зелёное сообщение

**LinkedIn:**
- Кнопка: «Apply» / «Easy Apply»
- LinkedIn подтягивает данные из профиля
- Иногда доп. вопросы

## 🟢 Канал B: Email (через Poste.io)

Если вакансия принимает отклики по email:

1. **ResumePro готовит:**
   - Адаптированное резюме (.md + .docx/.pdf)
   - Сопроводительное письмо в теме письма

2. **Конвертировать документ:**
   ```bash
   python3 ~/.openclaw/plugin-skills/submit-resume/scripts/convert-resume.py \
     ~/workspaces/resume-editor/versions/YYYY-MM-DD_Компания.md
   ```

3. **Отправить email:**
   ```bash
   python3 ~/.openclaw/plugin-skills/submit-resume/scripts/send-email.py \
     --to "hr@company.ru" \
     --subject "Отклик: [Роль] — Борис Шевелев" \
     --body /tmp/cover-letter.txt \
     --resume ~/workspaces/resume-editor/versions/YYYY-MM-DD_Компания.pdf
   ```

**Формат письма:**
```
Тема: Отклик на вакансию [Роль] — Борис Шевелев

Тело: сопроводительное письмо (3 абзаца)

Вложение: резюме (.pdf)
```

## 🚨 Если что-то пошло не так

| Ситуация | Действие |
|----------|----------|
| Сайт требует вход | Сказать Борису: «Нужен вход на [сайт] для отклика» |
| Капча | Скриншот → Борису в Telegram |
| Форма сложная (много полей) | Скриншот → спросить у Бориса |
| Email не отправляется | Попробовать SMTP напрямую (127.0.0.1:25) |
| Google Drive не работает | Пропустить, сохранить локально |
| Файл не конвертируется | Приложить .md как есть |
| Нет браузера | Переключиться на email-канал |
| Ошибка отправки | Скриншот / лог → Борису |

## 🧰 Принципы

1. **Не придумывай.** Все достижения — только из CV Бориса.
2. **Их язык.** Пиши так, как написана вакансия. Их ключевые слова = твои формулировки.
3. **Честность.** Если gap — признай. Заполни смежным, но не ври.
4. **Без англицизмов.** В русском тексте — только русские слова.
5. **Цифры.** Достижения с цифрами работают лучше описаний.
6. **Трекинг.** Каждый отклик должен быть задокументирован.
7. **Google Drive.** Резюме всегда в Drive + локально.
