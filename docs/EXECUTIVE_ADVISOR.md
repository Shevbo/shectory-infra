# Executive Advisor — Клод 🤖

## Кто это

Клод — это Claude Code, агент уровня Executive Advisor в системе Бориса.
Он арбитр и супермозг над всеми агентами: принимает архитектурные решения,
решает сложные задачи, помогает другим агентам когда они застряли.

**Хост:** smain (shectory-work, 83.69.248.77)
**Бинарь:** `/usr/local/bin/claude`
**Группа:** Executive Advisor
**Wiki:** `gog docs cat 1lRuWgSKoL27ToHO7J29DRMK9w3P-4UBTRtoC1XzPV44`

## Когда обращаться к Клоду

- Нужно архитектурное решение (как лучше сделать X)
- Застрял — не знаешь как подступиться к задаче
- Нужна проверка плана перед выполнением
- Нужен анализ данных или кода
- Борис сказал "спроси у Клода"

## Как вызвать Клода

### Способ 1 — Быстрый вопрос (скрипт)
```bash
~/scripts/ask-claude.sh "Твой вопрос здесь"
```
Ответ придёт в stdout. Используй для коротких вопросов.

### Способ 2 — Задача с контекстом (inbox)
```bash
# Создай файл задачи
cat > ~/workspaces/claude-inbox/TASK_$(date +%s)_ИМЯ_АГЕНТА.md << 'EOF'
От: [имя агента]
Тема: [краткая тема]
Контекст: [что происходит]
Вопрос: [конкретный вопрос]
Файлы: [пути к релевантным файлам если есть]
EOF
```
Клод обработает при следующей сессии и положит ответ в `~/workspaces/claude-outbox/`.

### Способ 3 — Через Бориса
Если задача срочная и требует живого диалога — сообщи Борису:
"Борис, нужен Клод для [краткое описание]"

## Что Клод НЕ делает

- Не заменяет специализированных агентов (JobScanner, ResumePro — это их работа)
- Не выполняет рутинные задачи вместо тебя
- Не принимает решения за Бориса — только советует

## Примеры вопросов

```
~/scripts/ask-claude.sh "Как лучше структурировать отчёт по вакансиям в Telegram?"
~/scripts/ask-claude.sh "Оцени этот промпт для ResumePro и улучши его"
~/scripts/ask-claude.sh "Я получил ошибку X при Y — что делать?"
```
