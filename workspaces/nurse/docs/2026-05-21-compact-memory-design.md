# Compact Memory System — Nurse Agent

**Date:** 2026-05-21  
**Problem:** OpenClaw session accumulates all tool-call results in context. Single session grew to 1.2MB (969 messages, 523 tool results), sending 144K–334K tokens per request. Goal: keep total nurse prompt under 8K tokens.

---

## Architecture

```
User message → [Nurse reads context] → [Generates response + summary] → [Saves both to DB]
                       ↑
         memory.py context  (last 30 entries, ~1 line each)
```

### Components

**`~/workspaces/nurse/scripts/memory.py`** — SQLite-backed memory manager.

Commands:
- `save` (stdin JSON) — store entry, return `ID:<n>`
- `context [--chat <id>] [--last <n>]` — print compact context (default last 30)
- `get <id>` — return verbatim full text by ID
- `stats` — entry count and DB size

**`~/workspaces/nurse/memory/nurse_db.sqlite`** — SQLite database.

Schema:
```sql
entries(id, ts, role, chat_id, full_text, summary)
```

- `full_text` = verbatim original (never truncated)
- `summary` = 1-sentence distillation generated by the nurse's own LLM call

---

## Memory Protocol (in CLAUDE.md)

**Before responding:**
```bash
python3 ~/workspaces/nurse/scripts/memory.py context
```

**After responding:**
```bash
python3 ~/workspaces/nurse/scripts/memory.py save <<'JSON'
{"role": "user", "chat_id": "36910539", "full_text": "...", "summary": "суть в 1 предложении"}
JSON

python3 ~/workspaces/nurse/scripts/memory.py save <<'JSON'
{"role": "nurse", "chat_id": "36910539", "full_text": "...", "summary": "суть ответа"}
JSON
```

## Future: Therapist Mode

When therapist mode is enabled, the full `full_text` of relevant entries is retrievable via:
```bash
python3 ~/workspaces/nurse/scripts/memory.py get <id>
```

The therapist agent can reconstruct full session detail by fetching IDs of interest from the compact context index.
