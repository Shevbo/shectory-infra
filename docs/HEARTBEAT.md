# Heartbeat — периодические проверки

## Расписание (примерное, 2-4 раза в день)

### 🔔 Проверка почты (1-2 раза/день)
- Непрочитанные письма на mail.shectory.ru
- Срочные: от Бориса, от Марии/Даниэлы
- Важные: уведомления от GitHub (PR, issues), серверные алерты

### 📅 Проверка календаря (1 раз/день, утром)
- События на сегодня-завтра
- Family calendar напоминания

### 🚀 Статус проектов (1 раз/день)
- Gateway: работает ли openclaw-gateway
- gemini-live-service: отвечает ли voice.shectory.ru:8080
- Docker: все ли контейнеры живы
- Ключевые хосты: ping shectory-work, hoster, shevbo-pi, shevbo-cloud

### 📊 Dreaming (после каждого цикла, ~3:00)
- Проверить обновления MEMORY.md и DREAMS.md
- Накопилось ли достаточно recall для промоушена

## Если что-то требует внимания
- Важное → сразу написать Борису
- Если Борис спит (23:00-08:00 UTC+3) → не будить, записать и доложить утром
- Остальное → записать в memory/YYYY-MM-DD.md
