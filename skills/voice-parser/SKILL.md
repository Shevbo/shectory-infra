# Voice Parser — Парсинг голосовых сообщений

Читает .ogg аудиофайлы через Gemini Flash для транскрипции, анализа речи, интонаций, и содержимого.

## ⚠️ ОБЯЗАТЕЛЬНОЕ ПРАВИЛО

**При получении голосового сообщения от пользователя (аудио / голосовое / audio/ogg) — НЕМЕДЛЕННО запускай парсинг.**
Никаких "я не могу обрабатывать аудиофайлы", "это техническое ограничение", "напиши текстом". Сразу запускай скрипт.

Сообщение содержит путь к .ogg файлу в формате:
```
[media attached: /path/to/file.ogg (audio/ogg)]
```
Скопируй путь и передай его скрипту.

## Использование

```bash
# Транскрипция голосового
python3 ~/skills/voice-parser/scripts/parse_voice.py /путь/к/файлу.ogg

# С кастомным промптом (анализ интонации, тона, настроения)
python3 ~/skills/voice-parser/scripts/parse_voice.py /путь/к/файлу.ogg "Проанализируй тон и настрой говорящего"

# Batch — все свежие голосовые
python3 ~/skills/voice-parser/scripts/parse_voice.py batch ~/.openclaw/media/inbound/
```

## Telegram / WebChat флоу

Когда пользователь присылает голосовое:

1. OpenClaw сохраняет .ogg в `~/.openclaw/media/inbound/`
2. **НЕМЕДЛЕННО** запустить:
   ```bash
   python3 ~/skills/voice-parser/scripts/parse_voice.py <путь_к_файлу>
   ```
3. Результат (транскрипция + анализ) возвращается текстом
4. Дай ответ пользователю на основе содержимого голосового

## Как это работает

1. Читает .ogg файл
2. Кодирует в base64
3. Отправляет в Gemini 2.5 Flash через API
4. Gemini нативно обрабатывает аудио — транскрибирует, анализирует
5. Возвращает текст

## Конфигурация

API-ключ и прокси берутся из `~/.openclaw/openclaw.json`.
