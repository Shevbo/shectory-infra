## 📂 ЧТЕНИЕ ФАЙЛОВ И ДАННЫХ — твои возможности

Твоя LLM-модель НЕ видит картинки и НЕ читает бинарные файлы напрямую. Для ВСЕГО
есть инструменты. Никогда не отвечай «я не могу открыть файл» — запусти нужный скрипт.

### Любой документ или картинка → текст (ОДИН инструмент)
```bash
python3 ~/scripts/read-file.py <путь_к_файлу> ["подсказка для картинки"]
```
Сам определяет тип и возвращает текст:
- **.xlsx / .xls** (Excel) → таблица текстом
- **.pdf** → текст страниц (планы, отчёты, выписки)
- **.csv / .txt / .md / .json** → как есть
- **.png / .jpg / .jpeg / .webp** (скриншоты, фото) → распознавание через Gemini vision

Примеры:
```bash
python3 ~/scripts/read-file.py /path/Боря_питание.xlsx
python3 ~/scripts/read-file.py /path/план_тренировок.pdf
python3 ~/scripts/read-file.py /path/skrin_polar.png "Извлеки дату, тип тренировки, ЧСС-зоны, калории"
```
Результат используй как ввод от Бориса.

## 📒 Дисциплина памяти и федерации

**ПРАВИЛО:** любое **ключевое** изменение инфры/конфига/маршрутов (Lineman, прокси, WG, секреты, новые узлы, wrapper-скрипты, API-контракты между агентами) — **обязательно** в том же ходу:

1. Записать в свою долгосрочную память (`~/.openclaw/memory/`, `MEMORY.md`, или соответствующий файл агента) — что изменено и почему.
2. Сообщить в `~/FEDERATION.md` (через main/Tank или прямой patch если есть права) — это живая документация всей сети.
3. Если изменение касается поведения других агентов — оповестить их через federation API:
   ```bash
   curl "http://127.0.0.1:9090/api/agent/<agent_id>/message?from=<my_id>&message=ОБНОВЛЕНИЕ:%20..."
   ```

**Why:** без записи в память следующая сессия (твоя или соседнего агента) повторит уже отлаженное расследование с нуля. Это потеря времени и токенов.

**Триггеры (без исключений):**
- Routing (HTTPS_PROXY, маршруты Lineman, WG-роуты)
- Federation топология (узлы, агенты, mapping)
- Auth/секреты (где лежит, как читать)
- Wrapper-скрипты, демоны, cron-джобы
- API-контракты между агентами

Конкретные **значения** секретов в память **НЕ** писать ([[feedback_no_keys_in_chat]] / правило выше) — только имя/путь/смысл.
